## Мероприятия (ивенты) — 26.10.2026, пока ТОЛЬКО на тесте

- Каждое мероприятие — отдельный файл `data/events/<code>.json` (админка: коллекция «Мероприятия», можно
  создавать/удалять). Поля: `code` (латиница = имя файла), `enabled`, `dateFrom`/`dateTo` (YYYY-MM-DD, включительно,
  по дате телефона гостя), `emoji` (значок пузыря), `color` (→ CSS `--ev`), `cover` (обложка, необязательно),
  `title`/`subtitle`/`text`, `sections` (layout `list` | `promo`), у позиций `oldPrice` (зачёркнутая).
- `data/events.json` — список включённых с датами, собирает `tools/build_events.py`; ХРАНИТСЯ в git, publish.yml
  пересобирает и коммитит его вместе с переводами. Правишь мероприятия руками — запусти скрипт перед коммитом.
  (Раньше был в .gitignore — на тесте пропадал: у Marushevskii/Menu Pages ещё и собирается из ветки, без этого файла.)
- Подходят по датам несколько — показывается начавшийся позже. `tools/translate.py` переводит и `data/events/*.json`.
- Страница `#event` — не вкладка: нижние вкладки скрыты, вместо них «Вернуться в меню» (history.back → то же место меню).
- Пузырь как у Wolt (`#evBubble`): тащится пальцем, стоит там, где отпустили (`ev-pos` = {x, b}), не заходит на вкладки
  и за края; унести в «×» — скрыт до обновления страницы, вместо него мини-кнопка `#evMini` в шапке справа от названия
  (пока видна, языки уже — `.ev-mini-on`). Точка «новое» до первого открытия (`ev-seen`).
  Ключ ивента = файл + dateFrom + title.ru.

## Оформление мероприятий (темы) — 26.10.2026, пока ТОЛЬКО на тесте

- Поле «Оформление страницы» у мероприятия (`theme` в `data/events/*.json`): "" или `halloween`.
- `themeSite` (по умолчанию да) — «вау-эффект», так задумал пользователь: сайт открывается в ОБЫЧНОМ виде; после
  захода на страницу ивента (`evVisited`, только в памяти) и возврата всё меню в оформлении ивента; после перезагрузки
  снова обычный вид. Сцена, шапка с «небом» и крупные украшения — только на странице ивента (`.is-event.theme-...`).
- На основном меню в оформлении ивента — закреплённый фон `#evBgDeco` (theme.fixed(): паутина, паук, череп, дьявол),
  `position: fixed`, высота 100lvh (НЕ inset:0 — на iPhone при скрытии панелей Safari предметы прыгали). На странице ивента его нет.
- `body { overflow-x: clip }` обязателен: без него iPhone даёт сдвигать страницу вбок из-за украшений у краёв.

- Хеллоуин: ночная сцена (луна с текстурой, кривой замок, кладбище, тыквы в траве, мыши), фон всей страницы — звёзды,
