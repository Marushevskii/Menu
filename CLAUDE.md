## Контекст

- Пользователь общается по-русски, не программист. Объяснять просто,
  без жаргона, с примерами того, как это увидит гость или редактор.
- Проект живёт **только** в `D:\cafe-menu`. Не смешивать с `D:\AIcom\ComfyUI`
  (отдельный проект нейрофотосессий; фото позиций позже можно сделать там).
- Сайт — **только витрина**, без брони и заказов. Кухни нет.
- Вкладки: Кальян / Бар / Снэки / Акции. Настольные игры пока не нужны.
- GitHub Pages + Sveltia CMS (максимально простая) + запасной вариант на Google Таблице.
- 4 языка, ввод только на RU, автоперевод — официальный Google Cloud Translation API.
  Изменение RU-поля перезаписывает переводы и ставит метку «🔄 изменено».
- Стартовый контент: RU из старого меню как есть; EN/KA — исправленные из menu-audit.md;
  TR — составляем вместе с пользователем. Цинандали и Лимон Дроп не трогать до ответа владельца.
- Цены в лари (₾). Единицы объёма не пересчитываются, переводится только подпись (л → l → ლ → lt).
- Дизайн (14.10.2026): тёмная тема в цветах интерьера (винно-красные стены, тёплые лампы,
  дерево, кремовые диваны), фон — **готовая картинка** `assets/bg.webp` (дымка + шёлковые волны + зерно; рисует `tools/render_background.py`; живые SVG-фильтры/анимации на фоне тормозили iPhone — не возвращать), заголовки Cormorant Garamond, нижние вкладки
  — «жидкое стекло» (в Chrome/Android с преломлением через SVG-фильтр `#liquid`, на iPhone —
  размытие и блики). Все цвета в `:root` в `assets/style.css`. Логотип — позже.
- iPhone/Safari: нижняя панель не должна зависеть напрямую от `env(safe-area-inset-bottom)` (прыгает при скрытии панели Safari); подложка ленты разделов — плавная (`#chipsBg`, opacity из app.js); карточки ниже экрана проявляются при прокрутке (`.pre` → `.shown`).
- После правок CSS/JS увеличивать `?v=N` в `index.html`, иначе браузеры покажут старую версию.
