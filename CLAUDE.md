## Контекст

- Пользователь общается по-русски, не программист. Объяснять просто,
  без жаргона, с примерами того, как это увидит гость или редактор.
- Проект живёт **только** в `D:\cafe-menu`. Не смешивать с `D:\AIcom\ComfyUI`
  (отдельный проект нейрофотосессий; фото позиций позже можно сделать там).
- Сайт — **только витрина**, без брони и заказов. Кухни нет.
- Вкладки: Кальян / Бар / Снэки / Акции. Настольные игры пока не нужны.
- GitHub Pages + Sveltia CMS (максимально простая) + запасной вариант на Google Таблице.
- 4 языка, ввод только на RU, автоперевод — официальный Google Cloud Translation API.
  Изменение RU-поля перезаписывает переводы и ставит метку «🔄 изменено».
- Стартовый контент: RU из старого меню как есть; EN/KA — исправленные из menu-audit.md;
  TR — составляем вместе с пользователем. Цинандали и Лимон Дроп не трогать до ответа владельца.
- Цены в лари (₾). Единицы объёма не пересчитываются, переводится только подпись (л → l → ლ → lt).
- Дизайн (16.10.2026): палитра **«Warm Graphite»** (фон #232323/#303030, карточки #41403E, акцент #A99D8B,
  светлый акцент/цены #C5BBAA, текст белый). Прежняя винно-красная тема — в истории git (до 16.10).
  Фон — **готовая картинка** `assets/bg.webp?v=N` / `bg-wide.webp` (компьютер) (дымка + шёлковые волны + зерно; рисует
  `tools/render_background.py`, цвета там же; при перерисовке увеличить `?v=` в style.css и index.html;
  живые SVG-фильтры/анимации на фоне тормозили iPhone — не возвращать), заголовки Cormorant Garamond,
  нижние вкладки — «жидкое стекло». Все цвета в `:root` в `assets/style.css`. Логотип — позже.
- Фото позиций включаются галочкой `showPhotos` в `data/settings.json` (админка: «Показывать фото позиций»).
  Сейчас **выключено** — классический вид «название ··· цена». Версия с фото — тег git `v-photos`.
- iPhone/Safari: нижняя панель не должна зависеть напрямую от `env(safe-area-inset-bottom)` (прыгает при скрытии панели Safari); подложка ленты разделов — плавная (`#chipsBg`, opacity из app.js); карточки ниже экрана проявляются при прокрутке (`.pre` → `.shown`).
- После правок CSS/JS увеличивать `?v=N` в `index.html`, иначе браузеры покажут старую версию.

## Что делать дальше

Этапы — PROJECT.md §10. Выбран **автоматический** автоперевод (GitHub Action), не кнопка в CMS.

**Этап 1 (демо) сделан 13.10.2026:** `index.html`, `assets/style.css` (все цвета в `:root`),
`assets/app.js` (без текстов), данные в `data/`: `hookah|bar|snacks|promo.json` (вкладки),
`ui.json` (тексты интерфейса), `settings.json` (вкладки, языки, Wi-Fi, соцсети).
Все тексты — объекты `{ru,en,ka,tr}`. У позиции: `id` (латиница, по нему потом фото),
`price`, `amount`+`unit` (ml/l/g), `variants`, `priceFrom`, `photo`, `hidden`.
Локальный просмотр: preview «menu» из `.claude/launch.json` (порт 5173).
**Этап 2 (14.10.2026):** репозиторий https://github.com/Marushevskii/Menu (публичный, ветка `main`),
сайт https://marushevskii.github.io/Menu/ (GitHub Pages из корня `main`, есть `.nojekyll`).
Вход в GitHub на этом ПК через Git Credential Manager — `git push` работает без вопросов.
**Этап 3 (14.10.2026):** админка `admin/` (Sveltia CMS 0.227.2 с unpkg, настройки `admin/config.yml`,
вход по fine-grained токену GitHub — «Sign In Using Access Token»; кнопка «Sign In with GitHub» без
OAuth-посредника не работает). Редактор правит `data/hookah|bar|snacks|promo.json`, `data/settings.json`
(Wi-Fi, соцсети), `data/ui.json` (тексты). Технические настройки — `data/site.json` (в админке их нет).
Фото из админки → `photos/` (WebP, до 1400 px). При переезде на другой аккаунт — поменять `repo` в config.yml.
**Этап 4 (14.10.2026):** `.github/workflows/publish.yml` — на каждый push в main: `tools/translate.py`
(сравнивает с `github.event.before`, переводит только изменённые RU-поля через Google Translate v2,
format=html, ключ — секрет `GOOGLE_TRANSLATE_KEY`), коммитит переводы, деплоит Pages (источник Pages —
**GitHub Actions**). Метка `"auto": "🔄 изменено"` в языковом объекте, видна в сводках админки, сайт её
игнорирует. Словарь «не переводить» — `data/glossary.json`. Проверка без Google: `python tools/translate.py --base HEAD --fake`.
Фото: `python tools/photos.py <файл> <id>` → `photos/<id>.webp` (1200 px) + `photos/thumbs/<id>.webp`
(240×240), в позицию пишутся `photo` и `thumb` (`thumb` — скрытое поле в админке). Чужие/стоковые фото
(с водяными знаками) на публичный сайт не выкладывать — только показывать локально.
Ждём: ключ Google для автоперевода, проверку турецкого, ссылки соцсетей, свои фото позиций.
