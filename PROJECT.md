# AIR LOUNGE & BAR — меню-витрина для QR

Все принятые решения. Батуми, Грузия. Обновлено 13.10.2026 (вторая сессия).

## 1. Что делаем

Сайт-меню, который гость открывает, отсканировав QR-код на столе.
**Только витрина**: ни брони, ни заказов на сайте нет. Заказ принимает бармен
или кальянный мастер.
**Сначала телефон**, десктоп нужен только «чтобы не развалился».

## 2. Хостинг — бесплатно

- **GitHub Pages**: репозиторий → Settings → Pages.
- Адрес вида `https://<логин>.github.io/<репо>/`, позже можно подключить свой домен.
- Сайт статический, без сервера и базы.

## 3. Редактирование

### Основной способ — админка Sveltia CMS (`/admin`)
- **Максимально простая**: никаких лишних кнопок и технических полей.
  Редактор видит только список позиций по разделам, а у позиции: название, состав, цена,
  объём/вес, фото, «скрыть». Служебные поля спрятаны.
- **Вводим только на русском.** Остальные языки видны отдельными вкладками,
  в них можно поправить перевод руками.
- Сохранение = коммит в репозиторий, сайт обновляется сам за 1–2 минуты.
- Нужен бесплатный аккаунт GitHub у каждого редактора. История правок хранится,
  любую ошибку можно откатить.

### Запасной способ — Google Таблица (делаем тоже)
- Копия всего меню в Google Таблице: лист на раздел, столбцы RU/EN/KA/TR, цена, объём.
- **Обычный режим:** сайт берёт данные из админки, а таблица — резервная копия,
  которая обновляется автоматически.
- **Аварийный режим:** если админка недоступна, один переключатель в настройках —
  и сайт читает меню из таблицы. Правите таблицу — меняется сайт.
- Одновременно работает только один источник, чтобы правки не конфликтовали.

### Фото
- В первой сборке вместо фото стоят **аккуратные заглушки** (иконка раздела).
- Загрузка потом — двумя способами:
  1. по одному: в админке у позиции кнопка «Загрузить фото»;
  2. пачкой: положить файлы в папку `photos/` с именами вида `pina-colada.jpg`
     (список имён дам), скрипт сам сожмёт их в WebP, сделает превью и привяжет к позициям.

## 4. Языки — 4

| Код | Язык |
|---|---|
| `ru` | русский — **основной, ввод только на нём** |
| `en` | английский |
| `ka` | грузинский |
| `tr` | турецкий |

- Переводится всё: разделы, кнопки, подписи, подвал, заголовок вкладки,
  служебные фразы. Ни одной строки, зашитой в код.
- Переключатель языка в шапке, выбор запоминается.
- **Первый вход:** язык берётся из системного языка телефона гостя (тот, на котором
  у него интерфейс телефона). Если это не RU/EN/KA/TR, показываем **английский**.
- Пропусков перевода быть не должно. На всякий случай, если поле пустое, показываем
  английский, а не пустое место.
- Шрифт с поддержкой грузинского (Noto Sans Georgian).

## 5. Общие для всех языков

- **Цена — лари (₾)**, одна на все языки, без конвертации.
- **Объём и вес:** число и единица общие, а **подпись единицы переводится**:
  `0,5 л` / `0.5 l` / `0.5 ლ` / `0,5 lt`, `50 г` / `50 g` / `50 გ` / `50 gr`.
  Единицы не пересчитываются: литры остаются литрами.
- Фото, метки «скрыть / закончилось», порядок.

## 6. Автоперевод — Google Cloud Translation (официальный API)

- Бесплатно **500 000 символов в месяц**. Всё меню ≈ 15–25 тыс. символов,
  то есть полный перевод меню можно сделать ~20 раз в месяц бесплатно.
- Нужен аккаунт Google Cloud с картой (подключает владелец). Ключ хранится в секретах
  репозитория, на сайте его не видно.

**Как работает:**
```
Админка: сохранили RU → GitHub Action → Google Translate → EN / KA / TR
```
- **Любое изменение русского поля** переводит это поле заново на все языки,
  даже если там уже был текст.
- У переведённого поля появляется метка **«🔄 изменено»**: видно, что именно
  поменялось, проще найти и проверить. После проверки метку можно снять.
- Ручная правка EN/KA/TR сохраняется, пока не изменится русский оригинал этого поля.
- Переводится только то поле, которое изменилось, а не всё меню.

**Словарь «не переводить»** (урок из старого меню, см. [menu-audit.md](menu-audit.md)):
название заведения, бренды (Jameson, Olmeca, Jägermeister…), классические коктейли
(Cuba Libre, Old Fashioned…), вина (Киси, Саперави…). Для них берётся готовый вариант
из словаря, а не машинный перевод.

**Стартовые переводы** делаем не машиной: берём исправленные EN/KA из menu-audit.md,
турецкий составляем вместе. KA и TR желательно один раз показать носителю.

## 7. Структура

```
[Шапка]       AIR LOUNGE & BAR · RU EN KA TR
[Чипсы]       разделы текущей вкладки, липкие сверху, листаются свайпом
[Карточки]    фото (заглушка) · название · состав · цена ₾ · объём/вес · метки
[Просмотр]    фото на весь экран по тапу
[Подвал]      Instagram · Telegram · Google Maps · Яндекс.Карты · Wi-Fi
[Вкладки]     Кальян · Бар · Снэки · Акции        ← низ экрана, закреплены
```

Кухни нет. «Атмосферы» и брони нет. Настольных игр пока нет (возможно, позже).

**Карточки крупнее**, чем у образца: фото побольше, крупный шрифт цены.

**Раскладка контента из текущего меню (RU):**
- **Кальян:** Классический / Молочный / Лимонадный + примечания про время и 1 кальян на 3–4 человек.
- **Бар:** Классические коктейли · Авторские коктейли · Коктейль вне меню (конструктор 5 шагов) ·
  Шоты · Пиво · Крепкий алкоголь 50 мл · Вино 0,7 · Лимонады · Холодные напитки ·
  Чаи классические · Чаи травяные · Чаи фирменные · Милкшейки · Протеиновые шейки.
- **Снэки:** Джерки · Орешки · Чипсы · Сухарики.
- **Акции:** Скидка 10 % в ДР · Коктейль за отзыв · Шот за отметку в Instagram ·
  Такси в дождь · Каждый 13-й кальян · VIP-комната (депозит 25 ₾/час).
- Везде внизу: «В заведении запрещено употреблять свои напитки».

## 8. Внешний вид

- Логотип, цвета и настроение — **позже**. Сейчас нейтральный аккуратный дизайн.
- Все цвета и шрифты собраны в одном месте, поэтому смена стиля потом — это правка
  десятка строк, а не переделка сайта.

## 9. Технические требования

- Фото в WebP, 100–300 КБ, мини-превью отдельно (~240 px).
- Ленивая загрузка картинок.
- Крупные зоны нажатия (≥44 px), читаемый шрифт без зума.
- Без внешних трекеров.

## 10. Этапы сборки

1. **Демо-сайт**: всё меню (RU + EN + KA + TR) в 4 вкладках, заглушки фото, мобильный вид.
   Показываем, правим вид. Работает пока локально, у пользователя на компьютере.
2. **Публикация**: репозиторий GitHub + GitHub Pages, QR-ссылка работает с телефона.
3. **Админка**: Sveltia CMS, упрощённая форма, вход редакторов.
4. **Автоперевод**: GitHub Action + Google API + словарь + метки «🔄 изменено».
5. **Фото**: скрипт пакетной загрузки (папка `photos/` → WebP + превью).
6. **Google Таблица**: автокопия + аварийный переключатель.
